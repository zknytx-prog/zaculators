Percentage Increase Calculator

What This Calculator Estimates

Percentage increase measures how much a value has grown relative to its original amount, calculated by dividing the increase (new minus original value) by the original value and multiplying by 100. This calculator estimates percentage increase using the original and new values you provide, useful for tracking salary raises, price increases, growth rates, or any scenario involving growth from a starting point.

Frequently Asked Questions

How is percentage increase calculated?

Subtract the original value from the new value to find the increase, divide that increase by the original value, then multiply by 100 to express it as a percentage.

Why is the original value used as the base for percentage increase?

Percentage change is conventionally measured relative to the starting point, since that represents what you're comparing the growth against — this is the standard convention across most percentage increase calculations.

Can percentage increase exceed 100%?

Yes, unlike percentage decrease (capped at 100% for a decline to zero), percentage increase has no upper limit — a value can more than double, triple, or grow by any amount relative to its starting point.

How is percentage increase different from a ratio comparison?

Percentage increase specifically expresses growth relative to a starting point as a percentage, while a ratio might compare two values directly without that specific 'relative to original' framing.

What if the new value is actually lower than the original?

If the new value is lower, you're looking at a percentage decrease, not increase — using the dedicated percentage decrease calculator would give you the correct framing for that scenario.
