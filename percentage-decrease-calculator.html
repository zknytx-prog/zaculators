What This Calculator Estimates

Percentage decrease measures how much a value has declined relative to its original amount, calculated by dividing the decrease (original minus new value) by the original value and multiplying by 100. Frequently Asked Questions

How is percentage decrease calculated?

Subtract the new value from the original value to find the decrease, divide that decrease by the original value, then multiply by 100 to express it as a percentage.

Why does percentage decrease use the original value as the base, not the new value?

Percentage change is conventionally measured relative to the starting point, since that represents the baseline you're comparing the change against — using the new value as the base would give a different, less standard interpretation.

Can percentage decrease be more than 100%?

In some contexts (like tracking a negative-to-positive swing), you might see calculations exceeding 100%, but for straightforward decreases to a positive value, decrease percentage will be between 0% and 100%.

How is percentage decrease different from percentage change?

Percentage decrease specifically describes a decline, while percentage change is a more general term that could describe either an increase or decrease — decrease calculators typically assume the new value is lower.

What if the new value is actually higher than the original?

If the new value is higher, you're actually looking at a percentage increase, not decrease — using the dedicated percentage increase calculator would give you the correct framing for that scenario.
